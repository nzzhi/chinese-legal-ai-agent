# 离线 Demo 演示说明

`npm ci --ignore-scripts --no-audit --no-fund` 后运行 `npm run demo`，浏览器打开 http://127.0.0.1:3211。

建议用 2–3 分钟展示：填入固定合成案情 → 创建并查看事实 → 上传 `materials/transfer.txt` → 查看原文/核对关联 → 生成初步分析 → 查看法源缺口 → PDF 预览与下载 → 刷新读取同一版本。

说明旁白：“模型回答使用固定替身。上传读取、检索、核验、持久化和导出执行实际代码。样本只有两条历史法条摘录，效力未核，因此报告保留缺口；这次演示不证明模型或法律质量。”

替身只接受按钮生成的案情。不要通过修改文本尝试任意案例，也不要将真实案件输入 Demo。STRICT 实现保留，但固定替身不支持深度研究，选择后明确拒绝，不伪造结果。

截图来自实际浏览器页面，见 `docs/assets/`。没有发布原项目视频、历史模型响应或运行报告。运行时生成文件在被忽略的 `.local`，不是公开样例。
